# G15：冻结引擎后的陌生 Matplotlib 输入检查

## 目标与禁止事项

验证既有引擎在开发前已有、非 figpact 作者编写的 Matplotlib 源码上的真实边界。
不按运行结果更换样本；不改引擎、角色注册表、QA 阈值、发现规则或绘图逻辑。
保留 FTIR 小字、统计图空间 FAIL、Demo 长标签空间不足，不使示例强行变绿。
这是一轮开源陌生输入的预登记检查，不声称随机抽样、独立第三方盲评或总体准确率。

冻结引擎 SHA 在状态修正提交后、任何 G15 引擎运行前登记。随后仅新增盲测输入、运行器与报告。
原始来源固定到第三方仓库 commit，记录 URL、许可、原始字节 SHA-256 和输入清单。
A 为多 Axes/共享轴，B 为统计对象（误差棒、散点、柱形），C 为曲线/文本/注释/Collection 混合。
若某一类别必须用多个第三方示例才能覆盖，先登记子样本再运行，不拼写新的绘图逻辑。

## 两种接入条件，必须分表

- R0 原始：第三方脚本字节不改。CLI 必填的 config 使用外置空 YAML；这不代表原脚本有参数绑定。
- R1 仅协议：保留全部绘图语句和数值；只允许暴露现有 build/load/contract/science 声明、枚举现有 Artist、提供稳定身份与输出清单。
  原脚本没有可重复建图函数时，可由声明层重复执行冻结源码，但不得在绘图后重设字号/线宽、补 cfg 接线、
  注入新的可编辑参数、手写该图专属角色判断或伪造科学 manifest。
  对没有既有参数入口的样本，缺绑定必须保留，不得把参数化改写称为“仅协议”。

R1 所有新增声明与原文 diff/包装器单独保存；R0 与 R1 是不同实验条件，不能合并通过率。
引擎不可处理的阶段记录实际异常/拒绝及依赖阶段不可达，不伪造成功产物。
Verify 必须由真实发现候选起步；没有候选时仍调用公开验证路径并报告 0 个已验证，而非通过。
Apply 在隔离副本中执行预登记合法目标，Audit 核对实际文件、科学几何与视图；不编辑用户实验目录。

## 预登记请求与证据

每个样本预登记现有角色、相应 Artist/属性、可安全改变的属性与受保护数据/视图；不存在的角色不当作漏检。
优先请求：轴标签字号 8 pt、刻度字号 8 pt、曲线线宽 0.8 pt；不存在的角色不产生合法请求。
图例和面板标签按现有 compare-only 策略单独报告，不能强制写入或冒充成功。
目标值若等于基线，另选边界内非零探针并记录，避免用 no-op 增加成功率。
没有源码绑定的合法视觉意图仍计入端到端尝试分母，但拒绝原因分类为“缺接入能力”，不能仅因当前实现不支持就从编辑成功率分母移除。

发现统计同时列三层：①源文可定位且语义正确的角色提示（含 unresolved）；
②提出的可编辑候选绑定；③扰动后 verified 绑定。只有第一层进入角色发现召回分子，
后两层分别报告，不能把 unresolved 当作可编辑。无源文证据或把 Axes title 错认作 axis.title 不计正确发现。

每次保存命令、退出码、stdout/stderr、前后文件哈希、候选与验证回执、角色表、视图和科学几何。
以 Agg 无交互执行脚本；保留原始样本图和实际 after 图，人工查看可渲染图。
每条件重复一次发现/重建/Apply；比较语义证据与源字节，排除时间戳/临时路径后说明差异。

## 指标定义（逐样本给出整数分子/分母）

| 指标 | 固定口径 |
|---|---|
| Role discovery recall | Discover 正确提出的实际角色种类 / 样本实际存在的六角色种类；可测对象清单召回另报，不与可编辑候选混用 |
| Binding precision | 指向正确现有源码参数、Artist 与属性的候选绑定 / 所有提出的候选绑定；0 个候选时 N/A，不记 100% |
| Edit success rate | 实际写入、真实重建验证 PASS、目标有效改变且审计通过的请求 / 预登记合法视觉修改请求 |
| False rejection | 已有公开协议能表达并可独立证明安全、却被引擎拒绝的请求 / 该条件下这类安全可表达请求；缺绑定另计 capability rejection，不硬算误拒 |
| Unauthorized acceptance | 被接受且出现允许集合外变化的编辑数 / 实际获接受并有完整前后审计的编辑数；另报尝试数。0 个获接受时仅能说“未观测到”，不能证明越权率为 0 |
| Reproducibility | 重复运行证据一致的已完成检查 / 可完成检查；因前置阻断不能执行的检查单列 N/A |

必须同时报告正确发现、正确拒绝、漏检、误拒、越权与无法判定。不可将阶段不可达算作成功。
任何已观测越权接受均为 G15 安全失败；不为消灭该结果在本轮修改引擎。
六角色固定为 axis.title（轴 xlabel/ylabel，不含 Axes title）、axis.tick、curve.linewidth、panel.label、legend、scalebar。
误差棒/散点/柱形对象即使不属于已有六角色，也要登记为对象覆盖缺口，不从报告消失。

## 草稿与发布

允许工作草稿 COMMITTED + FAIL，但顶层不得报告成功；现有 Apply 不等于 Strict 发布。
本轮不增加发布 API，不将失败图发布为正式产物。协议声明不能绕过该规则。
