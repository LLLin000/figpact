# Figpact 检查器 UI/UX 规范与实测报告 (Apple Preview 启发版)

本文档记录了 figpact 检查器从旧版工程界面重构为「Apple 预览 (Preview) 启发式检查器」的设计决策、规范依据、文案演进对照、实测数据与边界限制。

---

## 1. 规范来源与设计依据 (Primary Sources)

本界面的交互布局与视觉层次遵循以下权威人机交互规范与官方指南，并针对 Windows Web 环境进行了原生化适配：

1. **Apple Developer: Human Interface Guidelines (HIG) - macOS Components**
   - **Toolbars (工具栏)**：工具栏应保持静雅克制 (Quiet & Unobtrusive)，仅提供与当前文档或视图直接相关的全局操作；控件采用分组与分段控制 (Segmented Controls)，清晰呈现互斥状态与辅助提示。
   - **Inspectors (检查器)**：检查器是显示所选对象详细属性的上下文面板，按信息层级组织。将核心属性与常用交互置于第一视线，次级技术标识（如哈希、GID、协议码）置于二级卡片或折叠区，避免专业术语干扰阅读。
   - **Sidebars (侧边栏)**：提供文档大纲或图元导航，支持一键收起/展开，不遮挡主内容区与检查器。
   - **Feedback & Status (反馈与状态)**：状态指示应准确、客观、平静，区分「预览示范」、「真实试算核验」与「会话内生效」，不使用模糊报警或诱导性保存字样。

2. **Apple macOS Preview (预览) 官方使用手册 (User Guide)**
   - **视图控制**：提供「放大 (+)」/「缩小 (-)」/「适应窗口 (Zoom to Fit)」三态组合，配合以鼠标指针为锚点的平滑缩放。
   - **文档标尺 (Rulers)**：在主视口上方与左侧提供毫米标尺，反映导出页面的真实几何尺度，且标尺随视口缩放与平移同步重绘。
   - **通用信息与详细信息分层**：顶部呈现图像基础模式与分辨率，底部技术状态栏呈现渲染引擎、帧摘要与版本证据。

3. **Windows Web UI 适配原则**
   - **去伪 macOS 化**：不添加仿 macOS 的红黄绿窗口控制球 (Fake Traffic Lights)，保持 Windows 原生顶栏与现代无衬线字体栈（`Segoe UI`、`Microsoft YaHei`、`-apple-system`、`PingFang SC`）。
   - **零外部运行时字体与远程 CDN 依赖**：严格符合本地 CSP (`default-src 'self'`)，不加载 Google Fonts、FontAwesome 等外部资源，所有图标与图形采用原生 Unicode 符号与纯 CSS 绘制。

## 2. 界面文案与视觉术语全量演进 (Old → New Rationale)

遵循「第一眼通俗中文」原则，对所有静态及动态文案进行重写，将所有技术标识（GID、摘要、协议字段）归入二级技术细节，消除「检查通过」等模糊字眼，严格区分「会话试算」与「磁盘源文件保护」。

### 2.1 关键交互与核心模式对照表

| 界面位置 / 状态 | 旧文案 (Old) | 新文案 (New) | 演进依据与 UX 理由 |
| :--- | :--- | :--- | :--- |
| **引线说明 (重点)** | 科学锚点固定，引线可随关联标签重建，本界面不能编辑或独立拖端点。 | **移动标签时，引线会跟着调整；指向峰的位置不变。这里不能单独移动引线。** | 消除晦涩学术术语，用通俗主动句清晰表达关联标签与引线的因果关系，直接说明引线不可单独拖动。 |
| **会话接受按钮** | 接受 / Accept | **接受到会话** | 严谨限定作用域为内存会话，彻底杜绝用户误以为点击后会保存至磁盘或正式出图。 |

| **调整位移标签** | dx (mm) / dy (mm) | **水平 ΔX (mm) / 垂直 ΔY (mm)** | 直观展示二维几何调整轴向。 |

| **试算按钮** | 试算 / Evaluate | **试算排版** | 强调是对整体布局几何与科学约束进行真实物理试算。 |

## 4. 架构约束与已知边界 (Architectural Invariants & Limits)

1. **SVG 显示协议不替代 Agg 几何**：
   - 实际测量证明，Matplotlib RendererAgg 与纯 SVG 导出的文本包围盒存在微小字形度量差异（NMR 最大差异 0.232 mm，FTIR 最大差异 0.238 mm，3.91 标签差异 0.137 mm）。
   - 因此，检查器严格保持以 Agg 真实光栅图为底图、SVG 为高亮与幽灵辅助图层的设计，界面不虚假宣称实现了纯 SVG 矢量显示。
2. **会话单向隔离与源保护**：
   - 前端 Web 界面无论执行微调、试算、接受还是撤销，均仅在内存会话中进行试探重排，绝对没有写入磁盘文件（`.py`、`.yaml`、`.png`）的权限或路由。
3. **引线不可独立编辑端点**：
   - 科学图件的引线严格遵循「固定科学锚点 + 标签联动末端」法则，不提供几何自由端点拖拽器，以捍卫科学数据的严肃性与防篡改底线。
