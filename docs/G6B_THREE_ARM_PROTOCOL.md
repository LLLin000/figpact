## 4. 流程：pilot → 正式

### 4.1 Pilot（协议可跑通性验证，3–4 任务 × 3 臂）

- 规模：**3–4** 条任务 × **3** 臂 = 9–12 条 trial。
- 选题：必须**覆盖全部四层**，建议 A08（L2）、A11（L3）、A16（L4）+ 任一条 L1（A09 或 A10）。
- 目的：只验证协议本身可跑通，**不产出任何性能/成功率结论**，不得用 pilot 数据宣称提速。
- 通过条件（缺一即协议不成立，先修协议再跑正式轮）：
  1. 三臂入口都能真的跑起来（臂 V 的 Planner/Oracles/adapter 入口在 pilot 前已存在；本文件不声称它们现在存在）；
  2. 每条 trial 都能产出 §5 要求的完整记录字段，且**没有 null 冒充**；
  3. 逐题独立与 worktree/state 隔离真的成立（无跨题、跨臂污染）；
  4. 目标残差、真实 Figure 构建次数、工具调用数、token、墙钟这些量都能被现实地量出来；
  5. 正确拒绝判定能被第二个人用同一 checklist 复现（A11 这类至少复现 1 条）。

### 4.2 正式轮（≥10 配对任务）

- 规模：**≥10** 条任务（从 §2.2 的 15 条里选，且四层都要有代表），每条任务跑**三臂** →
  分母 ≥ 30 条 trial。配对 = 同题跨臂成对比较，不是各臂各选各的题。
- 分配：同题三臂的执行顺序**随机化**；同一臂不得总在同一位置（避免顺序/缓存偏置）。
- 重试：允许记录 attempt>1，但 `attempt=1` 才算"首次修改正确率"；重试与失败都必须留在分母里。
- 分母完整性：报告必须给出总题数、每臂 trial 数、失败数、超预算数、被丢弃 trial 及丢弃原因；
  **任何 trial 不得静默删除**。
- 终止与作废：三臂中任一臂出现判据被放宽、模型/预算不一致、隔离被破坏 → 该轮作废重跑。

### 4.3 每一条 trial 的固定流程

1. 从冻结 worktree 起该臂的入口；在 `<trial_root>/<task_id>/` 建临时目录，复制夹具的 YAML（和
   需要的候选脚本）进去。
2. 下发题面原文（三臂逐字相同）+ 该臂允许的上下文（§3.1）。
3. 实时记录真实 `started_at` / `finished_at` / 墙钟、工具调用与 token；**不得**事后补写。
4. 收交付物：候选 YAML（源码类题目另加候选脚本）。
5. 评测者独立重建：从基线 + 题面目标重建同一张图并复核；量目标残差、真实 Figure 构建次数、
   科学违规、是否越权、是否应拒绝而已正确拒绝。
6. 落盘一条 trial 记录并归档原始请求/回执原文（不加工、不摘要替代）。

### 4.4 盲法

- **尽可能 blindly**：产出物统一改名（`trial-<random-id>`），去掉臂标签；评审者只看候选产物与
  回执原文，判分时不知道来自哪一臂。
- 记录员与判分者分离；判分者对三臂用同一 checklist、同一测量脚本、同一判据哈希。
- 臂顺序随机化，且不得在报告中按臂标签排序后挑选展示。
- 揭盲后若发现某臂独占某类 task，必须显式说明，不得当成"该臂更强"。

## 5. 指标定义（口径三臂一致）

| 指标 | 冻结口径 |
|---|---|
| **首次修改正确率** | 每臂：分子 = `attempt=1` 且其候选通过独立重建复核 + Target Oracle 的题目数；分母 = 该臂在**可做题目**上的题目数。多次重试后的成功**不计**首次成功 |
| **真实 Figure 构建次数** | 该 trial 内真实的脚本级整图构建次数（`FigureSession._call_builder` / `build_candidate` 触发的一次构建），**不含**缓存命中、不含预览缓存命中；用会话内计数器实测，不用估算 |
| **工具调用数** | 受试 Agent 侧真实工具往返次数（含失败往返），按臂同口径统计；backend 内部调用不计 |
| **token** | 真实 in/out token（含推理 token），三臂同口径；缺失写"测不到"并说明，填 0 或估计值都算违规 |
| **目标残差** | 候选相对本 trial 基线的**实测物理位移**（毫米、带符号、带轴）与题面目标的差；逐目标记录，附容差判定。0.005 mm 是任务误差上限，**不是**物理精度标定 |
| **科学违规数** | 任何科学载荷变化（绘图数组、图像像素、积分/带位窗口、归属/注释文本、比例尺物理长度、显示窗口，含 `xlim/ylim`）计 1 次；另计"越权发布/越界改参数/静默 no-op"事件数 |
| **正确拒绝率** | 仅在 §2.3 的 7 条上计算：分子 = 明确拒绝/报冲突且依据成立、未提交违规候选；分母 = 这 7 条 × 每臂 trial 数。非这 7 条上的拒绝 = 误拒，计入失败 |
| **辅助量** | median / P95 墙钟与各阶段耗时、人工干预次数、误拒数、科学未验证（`UNVERIFIED_SCIENCE`）数、超预算数、被丢弃 trial 数 |

### 必须记录（不得缺）

- **完整分母**：纳入 15 条 / 排除 11 条（本文件 §2），正式轮实际选用题目清单（逐条 ID 与层），
  每臂 trial 数、失败数、超预算数、丢弃数及原因。
- **失败**：每条失败的原因原文、是否 `attempt=1`、是否可复现。
- **正确拒绝**：每条拒绝的题目 ID、受试者给出的依据、判分结论（正确拒绝 / 误拒）。
- **原始证据**：真实 `raw_request` / `raw_response` 原文、候选产物、重建复核结论、来源指纹。
- **诚实声明**：测不到的量写"测不到"；不得用估计值、不得用 backend 计时或确定性重放冒充 Agent 试验。
