## 机制修正 1：对象级差异检查（"无副作用"必须证明）

**问题**：科学指纹不变 ≠ 非目标对象不变。改 `axis_font_pt` 时曲线/峰位/坐标范围可能没变，但 legend 字号或其它 Axes 的标签可能一起变。

**要求**：扰动验证增加**对象级差异**：
```
actual_changes  ⊆  declared_allowed(对象集合, 属性集合)
```
- 采集方式：扰动前后对**全部注册/可识别 Artist** 做属性快照（gid、属性名、值），取差集；
- `actual_changes` = 实际发生变化的 (gid, property) 集合；
- `declared_allowed` = 契约里该绑定声明允许变化的 (gid, property) 集合；
- **只要出现未授权变化，验证判 FAIL**（不是 warn），并点名 gid + 属性 + 前后值；
- 不要求像素完全一致；允许清单由契约显式声明（默认可声明为"该 role 对应的对象上的该属性"）。

## 机制修正 2：角色注册表（定义先行）

**问题**：`role: axis.title → artist.kind: xlabel` 是否成立，取决于 `axis.title` 的定义。若它指 **Matplotlib 的 `Axes.title`**，该绑定就是错的。

**要求**：建立**角色注册表**（单一权威），逐条写明：
- 角色 id、**人类可读定义**、**允许的底层对象**（如 `axis.title` = **坐标轴标签** = `xlabel`/`ylabel` 文本；如需 `Axes.set_title` 则另立角色 `axes.title`）、**允许修改的属性**、**是否可跨图统一**、**不可统一的理由**。
- 契约、比较器、Agent 指南、GUI 文案**都引用同一份注册表**，不得各自解释。
- 若发现现有绑定与注册表定义不符 → **改定义或改绑定**，并在交付里写明改了哪边、为什么。
