## A：图例与草稿门禁

CCK-8 原图例位于 Axes 上方，但仍完整在最终画布内。120 DPI 实测：图例 bbox 为 `[202.28,270.77,489.94,291.18]` px，Axes 为 `[87.31,41.01,604.91,257.76]`，画布为 `[0,0,623.62,292.91]`；四边画布溢出均为 0。`clip_on=True`、`clip_box=None` 并不代表实际裁切。原 7.07 mm 报警把超出 Axes 错当裁切。

`qa.check_out_of_frame` 改为按最终画布测量图例；真实出画布仍阻断。结构化实测还包含实际 clip 区域短缺、线条／FigureImage 溢出、重叠面积、压线采样点和字形有效字号。回归覆盖合法轴外图例、出画布、实际 clip box、不可测量、重复身份和规格篡改。

草稿授权不解析报错文字。记录含规则、真实 Artist 身份、数值、单位、阈值、severity 和恶化方向；比较当前已保存工作状态与候选。新问题、数值恶化、未知规则、缺测量或身份歧义均拒绝。当前状态用真实构图测量，不把原图缺陷与已保存缺陷取并集，已改善问题不能借原图基线回退。

`apply(..., allow_draft=True)` 只是明确请求，不是绕过门禁。局部／科学／视图验证必须通过；页面候选绑定 revision 与 Overlay hash，必须明确点击“保存工作草稿”。保存状态为 `COMMITTED_DRAFT`，整图 FAIL 和问题数量保留。显式 `load_workspace` 可重开合格草稿；严格 `load`／`render` 不返回整图 FAIL 的 Figure，不写出版图片。源码漂移、外部 Overlay 冲突和新／加重 QA 均拒绝并保留旧字节。

真实 FTIR 浏览器验收使用只读项目示例，源码／配置／样式依赖哈希冻结；Overlay 与输出写临时目录。ylabel 8.5→9.5，明确保存草稿，停止服务后新进程重开，再修改 x 刻度并保存；两次均保留整图 FAIL，严格 PNG 导出没有生成文件。正常 PASS 的 G15b／原 G18 连续编辑也通过，未以它们替代草稿验收。

## 五轮串行试验

同一机器、单进程串行，每种样本真实执行 5 轮，共 20 轮；等待完整回归结束后才计时。流程包含启动、snapshot、预览、确认、重开、继续预览、同一 session 的外部冲突拒绝。每轮均实际重开匹配已保存值；20 次外部冲突均返回 `OVERLAY_CONFLICT`，冲突字节保留。继续预览不冒充第二次确认；FTIR 两次实际保存另由浏览器验收覆盖。

下表单位为秒，`p50 / p95` 使用 5 点线性插值；不是即时交互承诺。

|---|---:|---:|---:|---|
| FTIR | 79.02 / 80.59 | 13.22 / 14.63 | 14.66 / 14.90 | 5 次草稿；局部 PASS／整图 FAIL |
| NMR | 75.47 / 135.68 | 13.70 / 23.55 | 13.83 / 26.24 | 5 次草稿；局部 PASS／整图 FAIL |
| CCK-8 原完整流程 | 131.72 / 134.30 | 25.86 / 26.77 | 26.23 / 26.35 | 5 次 COMMITTED；PASS／PASS |

CCK-8 原流程每轮实际调用 `fs.export` 60 次、源脚本 `savefig` 180 次；5 轮合计 300／900。`fs.export` 包含子导出，耗时 p50／p95 为 50.74／51.30 秒；其中 `savefig` 为 39.91／41.12 秒，**两者不能相加**。纯构图上述调用均为 0。Inspector 自身画布渲染仍保留，不混作源脚本导出；额外验收 PNG 单列、不计入计时窗。

G19 三个样本均在预览后 `STYLE_REJECTED`，没有成功确认时间；G20 包含确认、重开及冲突验证。因此不能拿 G19 的 4–10 秒级总量宣称 G20 加速或减速。历史基线保留不回填，直接可比的是本次 CCK-8 原流程／纯构图的同口径对照。

试验记录提取器最初未展开 commit 的 tuple 响应，导致汇总状态缺失；保存的原始响应与计时未丢失。修正提取器后从 20 份原始响应重提取状态，父进程实际复核为 10 份草稿／整图 FAIL、10 份正式保存／整图 PASS；未重新伪造计时或把记录修复写成第二次试验。公开记录：[timing_results.json](../tools/g20/timing_results.json)。
