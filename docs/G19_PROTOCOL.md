# G19：真实科研图试用

## 范围

G18既有GUI权限、对象映射、Overlay事务语义冻结。仅窄修提交成功后的显示刷新故障，
不增加Artist/Agent/GUI重构、缓存或减少独立验证。
研究样本为真实FTIR、NMR及真实单面板统计图；用户已选择用现有单面板替代未找到的多面板统计源码。
因此多面板统计项明确未覆盖，不创建或冒充原有多面板图。
原始研究文件只读、哈希冻结，试用在隔离副本进行；仪器数据和私有源码不提交仓库。

## 首道门禁

真实Overlay apply COMMITTED+PASS后，强制后续StyleSession._rebuild异常。
HTTP必须保留提交事实，独立refresh_required/error；页面显示“文件已保存，但界面刷新失败”，
不得声称未写。旧帧不可继续编辑；重启后从已落盘Overlay恢复。
只在受信任测试启动器注入故障，不增加生产HTTP故障开关，不mock apply成功回执。

## 试用口径

记录原始脚本能否直接打开、所需依赖/路径准备、真实新增协议行数、已有集成替用户完成的工作。
支持且有唯一身份的轴标签/主刻度/Line2D样式作为合法修改；图例/峰标注/布局等存在但无控制权单独记录。
不把“对象有控制权但整图QA失败”归为“不支持”，不把“无控制权”归为QA失败。
每个样本尝试预览/连续编辑/取消/外部Overlay修改/重启，阶段不可达如实记录，不改图使其通过。
GUI试用为工程评估，不冒充独立普通用户研究。
与手动Python比较只报告可观察操作/准备量；无公平对照计时不能宣称提高效率百分比。

## 性能

至少5轮串行实测；保留失败轮及各阶段状态。p50/p95使用排序线性插值(n-1)*q。
同进程warm重复试用，单机小样本非SLA；成功轮与阻断轮分开解释。
分解导入、构图、身份解析、审计、QA、保存、渲染：工具进程内包装既有函数计时并在结束恢复，
嵌套采用exclusive时间避免双计，未归类时间另列。不改变原函数结果、不缓存、不省略验证。
预览/提交端到端与exclusive阶段分别报告，不能将阶段p95相加声称总p95。
没有保存/渲染阶段实际执行时记录0次/不可达，不伪造该阶段性能。
