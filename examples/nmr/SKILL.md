# Fig2 NMR 叠谱 —— 改图规则

**唯一可改的文件是 `nmr.yaml`。** `08 NMR.py` 只在「要新增一个参数」时才动。
数据、定标、归一化、峰归属永远不在配置里。

```bash
python "08 NMR.py"                     # 预览：出图，阻断项只打印（退出码 0）
python "08 NMR.py" --strict            # 验收：有**新增**阻断项则退出码 1，且不覆盖正式输出
python "08 NMR.py" --update-baseline   # 把当前全部阻断项记成存量基线
python "08 NMR.py" --config b.yaml     # 换一份配置做对比
```

命令行**严格解析**（`--strcit` 当场报错）；出图先写临时目录，最后一步才发布。

## 参数（必填 14 项 + 可选 1 项）

| key | 含义 | 范围 | 动它会怎样 |
|---|---|---|---|
| `canvas_w_mm` / `canvas_h_mm` | 画布物理尺寸 | 20–200 | 字号**不**跟着缩放 |
| `layer_gap` | 相邻谱层基线间距（数据单位） | 0–200 | 间距大 → 层间更空；太小 → 层与层糊在一起（阻断项会报） |
| `top_headroom` | 顶部预留（图例 + 顶层标注） | 0–400 | **固定值，不是实测预留**（与 FTIR 的差别）。收小 → 图例与顶层标注挤在一起 |
| `label_lift` | 峰标注距本层峰顶的净空 | 0–60 | 抬高标注会推开它自己的引线，也可能撞上层基线 |
| `label_min_gap_mm` | 标注间最小净空（mm） | 0.0–15.0 | 调大更稀疏防粘连，调小允许更紧密 |
| `label_max_dx_mm` | 自动避让最大横移（mm） | 0.0–25.0 | 调大允许在更大横向窗口内寻空，调小限制在峰近旁 |
| `label_lanes` | 允许的避让层数 | 整数 1–5 | 调大启用更多纵向层，调小限制在底层 |
| `peak_font_pt` | 诊断峰标注字号 | 3.0–12.0 | 变小可缓解"两个近峰标注叠在一起"；含下标时母体需 ≥7.143 |
| `legend_font_pt` | 图例字号 | 3.0–12.0 | 图例框变高，但**不改变**谱线可用高度（NMR 的预留是常数） |
| `note_font_pt` | `//` 截顶标记字号 | 3.0–12.0 | 只影响这个标记 |
| `axis_font_pt` / `tick_font_pt` | 轴标题 / 刻度数字 | 3.0–12.0 | 太大时刻度会撞轴标题 |
| `line_width` | 谱线线宽（pt） | 0.2–3.0 | 只影响观感 |
| `legend_cols` | 图例列数 | 整数 1–3 | 变列改图例框宽高 |
| `legend_anchor_x` | 图例水平锚点（0 左 1 右） | 0.0–1.0 | 太靠左会压住轴标题 |
| `shifts_mm`（可选） | 逐样品显示位移（mm，正数向上） | ±10 | **整组动**：该样品谱线 + 基线 + `//` 标记 + 锚定在它上面的峰标注与引线 |

未知 key、缺 key、非数字、NaN/Inf、超范围、非整数 → 直接报错退出。

## 关系型要求怎么落到参数上

| 要求 | 改什么 | 不要做什么 |
|---|---|---|
| 「某一层整体上/下挪一点」 | `shifts_mm.main.<样品id>`（样品id：`vancho` / `vanoh` / `vannh2` / `hama`） | 不要改数据或 `layer_gap`——那会动所有层 |
| 「四层之间拉开些」 | `layer_gap` | 不要逐层位移拼出来 |
| 「两个近峰的标注别叠在一起」 | 先 `peak_font_pt` 调小；不够再 `label_lift` | 不要删标注 |
| 「图例换个位置」 | `legend_anchor_x`（水平）/ `legend_cols` | 纵向不可调，见下 |
| 「整体抬高一点、别贴底」 | 目前**没有参数**——NMR 的纵向是 `layer_gap` + `top_headroom` 定的常数预留，没有 FTIR 那种整体位移旋钮 | 不要用四层位移假装 |

## 禁止

- 改 Bruker 原始数据、溶剂定标、归一化标尺（`PEAK_MAX_NORM`）、峰归属模板。
- 把 `PEAK_MAX_NORM` 加进 YAML——它是科学量，同时决定峰的相对幅度与截顶阈值。
- 越界时偷偷缩字号或裁数据——**报出来**。

## 验收

1. `python "08 NMR.py" --strict` 退出码 0；
2. `git diff` 里只有 `nmr.yaml`（从本次改造完成起算）；
3. 绝对毫米数一律**量导出件**（PDF/PNG），不要量交互环境。

**存量基线（`qa_baseline.json`）**：本图改造前就有 4 条排版几何问题——
`Ar–OCH$_3$ 3.91` 与 `–COOCH$_3$ 3.68` 两个标注重叠、`–COOCH$_3$` 与 `//` 压线。
它们已记入基线，所以 `--strict` 只对**新增**回归报警。

**⚠️ 这 4 条不是"参数没调对"，是"参数调不了"**：实测 `peak_font_pt` 4.4–6.0 ×
`label_lift` 2.4–6.0 的全部组合下，那个重叠**一直都在**。原因在标注分层算法
（`assign_label_tiers` 按最宽标签给统一横向间距），不在参数层。
所以基线在这里是"先记账、别挡住别的验证"，**不是"已解决"**：
要真正消掉它，得改分层算法或合并/删掉一个标注——那是脚本改动，不是 YAML 改动。
**别把 `--strict` 通过读成这张图已经干净了。**

**图注待补（科研表述）**：四层谱图做过**逐谱独立定标 + 去溶剂后归一化 + 垂直堆叠**，
纵向位置与幅度不可跨样品比较绝对强度。正式图注必须写明这一点。
